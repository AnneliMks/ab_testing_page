# A/B Testing

## Description  
Ce projet de data analysis a été réalisé de manière personnelle à partir d'un dataset Kaggle.  
L'objectif est de comparer le taux de conversion entre une ancienne page (`old_page`) et une nouvelle page (`new_page`) afin de déterminer si la nouvelle page améliore significativement la conversion des utilisateurs.

## Prérequis  
- Python 3.11  
- Bibliothèques utilisées : pandas, numpy, matplotlib, seaborn, statsmodels  

## Utilisation  
Le script `AB_testing.py` s'exécute en une fois.

## Structure du projet  
1. Exploration des données et visualisations.  
2. Préparation des données (suppression des doublons, conversion des types).  
3. Analyse des taux de conversion par groupe.  
4. Vérification de la taille d’échantillon pour la puissance statistique.
5. Test statistique : z-test pour deux proportions.  
6. Calcul des intervalles de confiance.  
7. Conclusion sur la performance des pages.

## Résultats  
Pas de différence significative entre les deux pages.  
La page ancienne (`old_page`) est préférable.

# A/B Testing – Landing Page 

## Description  
This personal data analysis project uses a Kaggle dataset.  
The goal is to compare the conversion rate between an old landing page (`old_page`) and a new landing page (`new_page`) to determine if the new page significantly improves user conversion.

## Requirements  
- Python 3.11  
- Libraries used: pandas, numpy, matplotlib, seaborn, statsmodels  

## Usage  
The `AB_testing.py` script runs in one go. 

## Project Structure  
1. Data exploration and visualizations.  
2. Data preparation (removing duplicates, type conversion).  
3. Analysis of conversion rates by group.  
4. Sample size verification for statistical power, c.  
5. Statistical test: z-test for two proportions.  
6. Confidence interval calculation.  
7. Conclusion on page performance.

## Results  
No significant difference between the two pages.  
The old page (`old_page`) remains preferable.
